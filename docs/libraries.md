# 使用ライブラリ一覧

## backend

| ライブラリ    | 用途                               |
| ------------- | ---------------------------------- |
| express       | Node.js用Webサーバーフレームワーク |
| cors          | クロスオリジンリクエストを許可する |
| dotenv        | .envファイルから環境変数を読み込む |
| @google/genai | Gemini APIクライアント             |
| zod           | スキーマ定義・実行時バリデーション |

## frontend

| ライブラリ | 用途                       |
| ---------- | -------------------------- |
| react      | UIフレームワーク           |
| vite       | ビルドツール・開発サーバー |
